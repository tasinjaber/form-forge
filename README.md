# Form Forge

A production-style React + TypeScript form experience focused on validation, accessibility and reusable interaction patterns.

## Features

- Typed form state
- Field-level validation
- Password visibility control
- Responsive layout
- Accessible labels and status feedback
- Vitest tests
- ESLint and GitHub Actions CI

## Run

npm install
npm run dev
npm run check

## Stack

React · TypeScript · Vite · Vitest · ESLint · GitHub Actions
